## RSA-Project
A mathematical and computational exploration of the inner workings of RSA cryptography with a focus on number theoretic foundations, algorithmic implementation, and analysis of computational complexity.

This project investigates the mathematical principles that make up the foundation for the RSA public key cryptosystem and demonstrates their implementation in Python. 

## Mathematical Foundations 
The paper discusses key ideas such as: 
- Euclidean and Extended Euclidean Algorithms
- Bézout's Identity
- Modular Inverses and Modular Arithmetic
- Euler's Totient Function
- Chinese Remainder Theorem (CRT)
- Mathematical Correctness of RSA

Computational complexity is also examined within the paper, including ideas such as: 
- Repeated squaring and modular exponentiation
- Time complexity in terms of integer bit length
- Integer factorization using trial division
- Pollard's Rho factorization algorithm



## Python Implementation 

The Jupyter notebook in the project includes short explanations and implementations of:
- Greatest Common Divisor (GCD)
- Extended Euclidean Algorithm
- Modular Inverse
- Modular Exponentiation using Repeated Squaring
- RSA Key Generation, Encryption, and Decryption
- Euler's Totient Function
- Chinese Remainder Theorem
- Integer Factorization Using Trial Division
- Pollard's Rho Factorization Algorithm
